# 📊 End-to-End Retail Sales Analysis

## 📝 Project Overview
This project involves a comprehensive Exploratory Data Analysis (EDA) of a retail dataset containing 1,000+ transactions. I used Python to clean the data, engineer new features (like Age Groups), and visualize key business metrics to identify growth opportunities.

## 📈 Key Executive Insights

### 1. Financial Performance
* **Total Revenue:** $456,000.00
* **Average Transaction Value (ATV):** $456.00
* **Top Category:** **Electronics** ($156,905), followed closely by Clothing ($155,580).

### 2. Consumer Demographics
* **Gender Split:** An equitable distribution of **51% vs 49%**, indicating a broad brand appeal.
* **Primary Age Demographic:** The **46-60** age group represents the highest revenue contribution, suggesting a mature customer base.

### 3. Seasonal Trends
* **Peak Month:** **May** ($53,150), suggesting high responsiveness to spring promotions.
* **Lowest Month:** **September** ($23,620), identifying a key window for future marketing interventions.

## 🛠️ Technical Stack
* **Language:** Python 3.x
* **Data Manipulation:** Pandas (Cleaning, Grouping, Binning)
* **Visualization:** Matplotlib (Bar Charts, Line Graphs, Pie Charts)

## 📂 Visualizations Produced
* `sales_chart.png`: Revenue by Product Category.
* `monthly_trend.png`: Sales performance over time.
* `gender_distribution.png`: Percentage split of customer gender.
* `age_distribution.png`: Revenue breakdown by age "bins."

## ⚙️ How to Reproduce
1. Ensure you have the dataset `retail_sales_dataset.csv` in the folder.
2. Install dependencies: `pip install pandas matplotlib`
3. Run the script: `python your_script_name.py`
